One original line of fortune-cookie wisdom for a software developer — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The fortune

> The estimate you give today is the apology you will write next month.

69 characters. An estimate, given lightly today, comes back next month as the apology the developer has to write — a fortune-cookie shape around a truth every developer recognises, with a quiet second meaning: the apology is both the explanation owed and the estimate itself, taken back.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is a single line of 1–120 characters and not only whitespace, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it back to verify the write.
